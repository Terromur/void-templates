# void-templates

Это коллекция templates packages для xbps-src Void Linux. Можно найти много полезных вещей, которые я не мог найти нигде, а так же экспериментальных, которые я сам развиваю.

# Использование
Склонируйте оригинальный репозиторий void-packages добавьте нужные пакеты в srcpkgs. Если вы планируете собрать GNOME, то зайдите в директорию и скопируйте все пакеты тоже туда. Так же не забудьте добавить в common дополнительные строки

```
cat common/shlibs >> void-packages/common/shlibs
```
